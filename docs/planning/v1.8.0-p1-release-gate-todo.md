### 已锁定产品决策（实施时不得再议）

| 决策 | 选择 | 理由 |
|------|------|------|
| Pending Hash | **保持 Schema 2 语义**：`outputs` 入 Hash 时仅含 Incremental Output + Hybrid **Root File**；Mirror 嵌套仅进 `next_state.outputs` / Local State | 与 v1.7.3 恢复协议兼容，无需 Schema 3 双算法 |
| 默认并行 | **`ftp_connections` 默认 = 1**；并行显式 opt-in | 不破坏共享主机/单连接服务器 |
| Pool 启动 | **先建满可用 Session，再启动全部 Worker**；不足时降级并 Warning；建连失败且无法降到 ≥1 才失败 | 避免部分上传后才发现并发不可用 |
| 自动改 RC | **普通 CLI 不再自动改 RC**；最多写用户级 script + 提示 `git-deploy completion install` | 消除静默破坏 `.bashrc/.zshrc` |
| 版本号 | 功能收口后统一 bump **`1.8.0`**（本 TODO 的 Phase 6；P1 修完再做，避免中途半发布） | 禁止继续以 1.7.3 构建 Wheel |
